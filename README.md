# ZBrush 2026 快捷键查询

一个纯 HTML 快捷键查询工具，**无需安装任何依赖**，手机和 PC 浏览器均可直接打开使用。

## 使用方式

直接打开 `index.html` 即可，或将文件传到手机浏览器中。

## 功能

- **122 条快捷键**，覆盖 12 个常用分类
- **实时搜索**：按快捷键名称、按键组合或功能描述筛选
- **分类筛选**：视图控制、笔刷控制、雕刻与几何、工具面板、子工具等
- **深色模式**：跟随系统主题自动切换
- **触控优化**：移动端单手操作适配
- **离线可用**：单文件，不依赖网络

## 快捷键分类

| 分类 | 说明 |
|------|------|
| 视图控制 | 视图环绕、适配屏幕、网格显示 |
| 笔刷控制 | B笔刷菜单、S大小、U强度、Alt反转 |
| 雕刻与几何 | Ctrl+D细分、Shift+D动态网格 |
| 变换操作 | Q绘制、W移动、E旋转、R缩放 |
| 遮罩与选择 | Ctrl遮罩、遮罩反转、隐藏显示 |
| 多边形组 | Ctrl+W分组、循环边选择 |
| 工具与面板 | Space菜单、F1-F10功能区 |
| 编辑操作 | 撤销、复制、删除隐藏 |
| 文件操作 | 新建、保存、导入导出 |
| 材质与渲染 | F6材质、Shift+B最佳渲染 |
| 子工具 | SubTool管理、切换 |
| 对称与轴 | X/Y/Z轴对称、镜像 |
